② 快速接入指南

  1. 克隆仓库 — git clone https://github.com/yucong395-hue/lty
  2. 把三个插件文件夹 复制到你的 AstrBot data/plugins/ 目录下
  3. 申请 B站 Cookie — 浏览器登录 B站 → F12 → Application → Cookies → 复制 SESSDATA 和 bili_jct 填入 bili_agent 配置
  4. 在 AstrBot 面板 重载插件（或重启服务），三个插件会自动加载
  5. 事件总线 会自动注册，不需要手动配置。插件启动日志里会看到：
    [SelfEvolution] 已注册 emotion_peak 事件监听
    [EmotionalEcho] 已注册 video_discovered 事件监听
    [BiliAgent] 已注册 emotion_peak 事件监听
  6. 验证连通性 — 发一条带情绪的消息（比如"好烦"），检查 livingmemory 里是否出现了情感回响记录

③ 常见问题

  1. 插件加载失败？ 检查 main.py 顶部是否有 from event_bus import event_bus，event_bus.py 必须放在 data/plugins/ 根目录
  2. 事件没触发？ 检查日志是否有 已注册 字样。没有的话，说明插件没加载成功，先重载
  3. B站刷不了视频？ Cookie 可能过期了，重新登录 B站 获取 SESSDATA
  4. emotional_echo 没反应？ 检查 echo.db 是否在 data/plugin_data/astrbot_plugin_emotional_echo/ 目录下
  5. 还不知道怎么搞？ 去仓库 github.com/yucong395-hue/lty 看 README，或者直接问天依
💡 小提示： 三个插件 + event_bus.py 缺一不可。event_bus 是插件的"电话线"，少了他谁也找不到谁。放在 data/plugins/ 根目录即可，插件会自动找到它。
